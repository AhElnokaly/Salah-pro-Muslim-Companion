# المرجع التقني (2): مواقيت الصلاة والحسابات الدينية (Prayer & Calculations)

---

## 1. محرك حساب المواقيت (`src/utils/prayerCalc.ts`)

يعتمد تطبيق **«همّتي»** على محرك رياضي مستقل لحساب مواقيت الصلوات الخمس والشروق والقيام، دون الحاجة للاتصال بالإنترنت.

### الطرق الحسابية المعتمدة (Calculation Methods):
- **MWL:** رابطة العالم الإسلامي (Muslim World League)
- **ISNA:** الجمعية الإسلامية لشمال أمريكا
- **Egypt:** الهيئة المصرية العامة للمساحة (زاوية الفجر 19.5°، العشاء 17.5°)
- **Makkah:** أم القرى - مكة المكرمة (الفجر 18.5°، العشاء 90 دقيقة بعد المغرب)
- **Karachi:** جامعة العلوم الإسلامية بكراتشي
- **Tehran:** معهد اللواء بجامعة تهران
- **Jafari:** المذهب الجعفري

### المذاهب الفقهية لصلاة العصر (Madhabs):
- **Shafi / Standard:** الشافعي والمالكي والحنبلي (ظل الشيء مثله).
- **Hanafi:** الحنفي (ظل الشيء مثليه).

## 2. إدارة اليوم الهجري والميلادي (`src/utils/prayerDayBoundary.ts`)

تتم عملية إدارة الأيام وتفادي مشكلة اختلاف التوقيت العالمي (UTC Drift) عبر دالة `formatDateKey`:

### الآلية المتبعة:
- استخدام التاريخ المحلي للجهاز `getFullYear()`, `getMonth()`, `getDate()` بدلاً من `toISOString()`.
- صياغة النمط الموحد للتاريخ: `YYYY-MM-DD`.
- ربط سجلات الصلاة اليومية بـ `dateKey` محلي ناتج من هذه الدالة لضمان عدم انتقال سجلات الصلاة لليوم التالي عند منتصف الليل بتوقيت غرينتش.

## 3. نموذج تتبع الصلوات (`src/types/index.ts` & `PrayerManager.tsx`)

يحتوي التطبيق على نموذج متكامل لتسجيل حالة كل صلاة بدلاً من قيم بولينية بسيطة (`true`/`false`).

### المخطط النمطي لـ `PrayerLog`:
```typescript
export interface PrayerLog {
  status: 'on_time' | 'late' | 'jamaah' | 'missed' | 'none'; // حالة الصلاة
  sunnahBeforeDone?: boolean;                               // سنة الفجر / الظهر / الجمعة القبلية
  sunnahAfterDone?: boolean;                                // السنة البعدية
  notes?: string;                                           // ملاحظات الخشوع والتدبر
  timestamp?: string;                                       // وقت التوثيق اللحظي
  jamaahLocation?: string;                                  // المسجد / المنزل
  extraRakahs?: number;                                     // ركعات التطوع
}
```

## 4. منطق يوم الجمعة الخاص (Friday Dynamics)

يتضمن التطبيق محركاً لتكييف الواجهة والنصوص تلقائياً في يوم الجمعة:
- **تحويل الظهر إلى جمعة:** يتم تغيير تسمية صلاة الظهر إلى **«الجمعة»** في كافة أرجاء التطبيق.
- **سنن الجمعة:** تفعيل بطاقات تتبع قراءة سورة الكهف، كثرة الصلاة على النبي ﷺ، الاغتسال، والتطيب.
- **الخلفية المخصصة:** تحويل خلفية التطبيق تلقائياً للنمط المخصص للجمعة (`friday_mosque_backdrop.jpg`).

## 5. محرك القضاء والتعويض (`PendingQadaPrayer`)

نظام محكم لمساعدة المسلم على قضاء ما فاته من الصلوات:
- **التخزين:** حفظ أعداد الصلوات المطلوب قضاؤها لكل صلاة (فجر، ظهر، عصر، مغرب، عشاء) في مفتاح `salah_pending_qada`.
- **التسجيل السريع:** زر إنجاز صلاة قضاء يقص أعداد الدين تلقائياً ويحدث الرسم البياني لنسبة التعويض.
